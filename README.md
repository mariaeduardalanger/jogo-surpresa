# 🎁 Surprise Game: Interatividade e Mistério

Este é um projeto focado em **Experiência do Usuário (UX)** e **Engajamento**. O objetivo aqui foi criar uma aplicação interativa onde o jogador percorre desafios simples para desbloquear uma "surpresa" final (uma mensagem, imagem ou som).

Projetos como este demonstram a capacidade de criar interfaces amigáveis e fluxos de jogo que mantêm o usuário interessado até o fim.

---

## ✨ Funcionalidades

- **Progressão por Desafios:** O conteúdo final está bloqueado atrás de mini-metas ou cliques estratégicos.
- **Feedback Visual Dinâmico:** Uso de cores e textos que mudam conforme as ações do jogador.
- **Sistema de Recompensa:** Uma tela final personalizada que só é acessível após a conclusão da lógica do jogo.
- **Código Limpo:** Estruturado de forma que a "surpresa" possa ser facilmente alterada para diferentes ocasiões.

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**: Linguagem base.
- **Pygame ou Terminal**: (Ajuste aqui conforme sua versão) para a interface do usuário.
- **Random/Time**: Para criar pausas dramáticas e elementos inesperados.
